# Calculadora con Sobrecarga de Métodos (Java OOP)

Este proyecto demuestra el concepto de **Sobrecarga de Métodos (Method Overloading)** en programación orientada a objetos usando Java. Permite realizar operaciones aritméticas básicas (suma, resta, multiplicación y división) aceptando diferentes cantidades de argumentos.
